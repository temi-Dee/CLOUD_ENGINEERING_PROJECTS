1. Configure AWS OIDC Provider:

2. Create GitHub Repository:
   gh repo create my-app --public --source=. --remote=origin
   
   Or manually:
   - Go to https://github.com/new
   - Create repository named: my-app
   - Run: git remote add origin https://github.com/temi-Dee/my-app.git

3. Configure GitHub Secrets:
   gh secret set AWS_ACCOUNT_ID --body "YOUR_AWS_ACCOUNT_ID"
   gh secret set S3_BUCKET_NAME --body "YOUR_S3_BUCKET_NAME"
   gh secret set CLOUDFRONT_DISTRIBUTION_ID --body "YOUR_CF_DIST_ID"

4. Push to GitHub:
   git branch -M main
   git push -u origin main

5. Monitor Pipeline:
   gh run list
   gh run watch
